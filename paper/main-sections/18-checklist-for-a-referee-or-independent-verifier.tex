\section{Checklist for a referee or independent verifier}

\begin{enumerate}
\item Confirm the convention and that only proper circles are counted.
\item Check the exact triple-partition identity and carrier intersection bounds.
\item Run the quick audit and compare the archive SHA-256.
\item Run the full replay from a clean extraction.
\item Inspect all final markers and ensure no timeout is interpreted as \texttt{NO}.
\item Review the profile completeness tables for $n=12$ and $n=13$.
\item Check the projective algebra in the $23T+9D$ obstruction independently.
\item Reimplement at least one large finite search if possible.
\end{enumerate}
