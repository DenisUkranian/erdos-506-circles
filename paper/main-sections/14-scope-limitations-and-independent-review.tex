\section{Scope, limitations, and independent review}

The result is a computer-assisted theorem, not a formal proof in a proof assistant.  The human-readable reductions isolate finite exact searches, but trust remains distributed among the mathematical reductions, source code, compiler/runtime, and retained certificates.  The archive substantially narrows the trusted computing base by using exact integer/rational arithmetic, independent cross-checks for critical branches, manifests, clean extraction, and replay.

Particularly valuable independent work would include a clean-room implementation of the $n=12$ allowable classification, the $B=80$ residual search, the $B=82$ $D$-frame line test, or the $23T+9D$ projective obstruction.  Any discovered error should be reported against the immutable release checksum and the exact case identifier.
