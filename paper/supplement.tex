\section{Convention and theorem boundary}

The package concerns distinct planar points that are not all collinear and not all concyclic.  Only proper Euclidean circles containing at least three selected points are counted.  The literal Erd\H{o}s wording without a collinearity exclusion has the degenerate value zero.

The canonical theorem verified by the package is
\[
 f(8)=17,
 \qquad
 f(n)=1+\binom{n-1}{2}-\left\lfloor\frac{n-1}{2}\right\rfloor
 \quad(n\ge9).
\]
The two new finite terminals are $f(12)=51$ and $f(13)=61$.

\section{Trust and failure model}

The proof is not formalized in a proof assistant.  Its trusted base consists of:
\begin{itemize}
\item standard integer and rational arithmetic in Python and C++;
\item the correctness of the mathematical reductions exposed in the manuscript and proof ledgers;
\item the operating system, compiler and interpreter used for replay;
\item the integrity of the released finite input tables and source code.
\end{itemize}

The release uses fail-closed semantics.  A timeout, process crash, missing file, malformed output, missing final marker or checksum mismatch is a verification failure, never a proof of impossibility.  Superseded working packages that violated this rule are not included in the canonical archive.

The exceptional $B=67$ profile $(40,15,12,0)$ has one local degree vector.  Fixing two 5-blocks gives three canonical intersection sizes.  Complete searches visit 26,734,131; 96,566,209; and 219,998,191 five-block nodes respectively, with no survivor.

The package checks profile coverage, degree-table regeneration, retained outputs and special-case completeness.

\section{Finite ledger for $n=13$}

Under $q\le60$, the inherited package gives $B\ge80$.  The $B=83$ package proves $L\le23$, hence $B\le83$.  The four levels are independently terminal.

\subsection{$B=80$}

Fourteen profiles are partitioned as follows:
\begin{itemize}
\item four inherited Farkas-plus-residual terminals ($b_5=13,14,15,16$, $b_6=2$);
\item one exact Cuntz local terminal $(46,20,12,2)$;
\item three $b_6=5$ rows excluded by the convexity contradiction $21>20$;
\item three rows ($b_5=6,10,11$, $b_6=2$) with no local degree system;
\item three rows ($b_5=7,8,9$, $b_6=2$) producing 695 exact branches.

The fresh residual search visits 5,829,152,493 five-block nodes and finds no survivor.  The audit verifies all 63 task shards, no timeout and full branch coverage.

\subsection{$B=82$}

There are eight pure profiles $b_6=0$, $b_5=10,\ldots,17$, and three mixed profiles $b_6=3$, $b_5=5,6,7$.

The pure reduction has 419 canonical $D=(9,7,6,0)$ local frames.  All profiles except $b_5=14$ fail before a complete 5-block family. The mixed branch has three point-orbit types and 4741 exact degree vectors.  No generalized-circle packing survives.

\subsection{$B=83$ and the line bound}

For $L\ge24$, pair/Melchior arithmetic leaves only $24T+6D$ and $25T+3D$, both excluded by fresh rooted allowable searches.  Thus $L\le23$.

At $B=83$, only $22T+Q+6D$ and $23T+9D$ remain.  The mixed type has 44 rooted cases, all terminal.  The all-triple type is enumerated in 15,565,063 nodes, yielding 96 labelled systems and one unlabelled hypergraph.  An explicit projective parameterization gives polynomial identities that force $w=0$ despite the distinctness requirement $w\ne0$.

\section{Recommended independent checks}

The strongest independent audit would not merely rerun the same binaries.  Recommended clean-room targets are:
\begin{enumerate}
\item regenerate the $n=12$ 118-type local classification;
\item regenerate the thirteen $n=12$ profile table and the count 4479;
\item independently enumerate the $n=13,B=80$ degree systems and 695 branches;
\item independently test the 7104 $B=82,k=14$ complete families for a line-22 skeleton;
\item reconstruct the 96 labelled $23T$ systems and their unique isomorphism class;
\item verify the projective polynomial identity symbolically or by a proof assistant.
\end{enumerate}

\section{Archival and citation policy}

The verification DOI should cite a specific immutable release.  Corrections must be made as a new version with a new version DOI, retaining the old record.  Public claims should identify the exact release SHA-256.  Historical failed/WIP packages may be archived separately for research history but must not be confused with the canonical proof object.

\section{Generative-AI disclosure}

Generative-AI systems assisted exploratory proof search, code drafting, debugging, orchestration and writing.  They are not authors.  The named human author(s) must review and accept responsibility for the released claims and files.  AI-produced assertions are not certificates; only explicit mathematics, exact source, inputs, outputs, manifests and replay commands enter the proof record.
