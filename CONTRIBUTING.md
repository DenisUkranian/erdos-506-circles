# Contributing

The highest-priority contributions are independent verification and proof simplification.

Please open an issue containing:

- operating system, Python and compiler versions;
- the exact release SHA-256;
- command executed;
- complete stdout/stderr;
- whether the issue affects soundness, completeness, portability or documentation.

For mathematical objections, identify the exact lemma, finite case, input table or completeness claim. For code changes, add a regression test and do not weaken fail-closed behavior: timeout, crash or missing output must never be interpreted as impossibility.
