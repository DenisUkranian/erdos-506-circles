# Shifted-endpoint longest-edge strip obstruction

22 September 2026. A conditional geometric theorem, not a solution of Erdős #634.

## Statement

Let a bounded convex polygon Ω be tiled by congruent triangles with integer side lengths a,b,c, with c a longest side. Reflections and T-junctions are allowed.

A real c-edge PR is parallel to an exterior supporting side, and its tile's opposite vertex lies on that side. Measure signed distance along P→R with coordinates 0 and c. An edge UV of a second tile is collinear, belongs to a tile on the opposite side, and overlaps PR in positive length. Orient U→V forward, with coordinates δ and θ=δ+d, d∈{a,b,c}.

Let L be the forward exit distance from P, and S={A*a+B*b+C*c : A,B,C≥0 integers}.

**Necessary condition:** there is an integer j≥1 with j*c≤L and j*c−θ∈S.

In particular, a nonintegral θ is impossible at any target size. For integral θ, the finite semigroup test is a sound obstruction. The theorem does not assume that an arbitrary line is a seam.

## Proof

If the common tile area is Δ, the strip width is 2Δ/c. A tile supported on this line on the strip side, with edge length e, has altitude 2Δ/e and must fit in the strip. Thus e≥c, so e=c.

The initial forward endpoints are c and θ, both positive. If equal, the condition holds with j=1 and no added edge. Otherwise the earlier endpoint is strictly inside the actual opposite edge. That edge prevents a new tile from crossing the line immediately beyond the endpoint, forcing a new collinear edge on the side that ended. The new edge cannot extend backward through the endpoint, as that would overlap the previous tile on the same side.

Consequently the forward endpoints always have forms j*c and θ+A*a+B*b+C*c. This induction uses an existing opposite edge, never an unjustified continuation after a true seam end. A finite tiling cannot add positive edges indefinitely, and no tile can cross the exterior boundary. It must therefore reach a common endpoint before or at exit. This proves the condition. If θ is not integral, equality to the integer j*c is impossible. ∎

## Relation to earlier work

For (a,b,c)=(uv,v²−u²,v²), the earlier same-origin c/b case has θ=b and L<vc. Its obstruction follows because a short j*c decomposition cannot contain b.

For a same-origin a/c mismatch, the first arithmetically possible coincidence is j=u, because v*a=u*c. In fact, the short-c decomposition gives A=v*h, B=0, C=j−u*h; A≥1 requires j≥u. Hence L<uc also obstructs that configuration.

Different starts, either endpoint ordering, any opposite edge length and any scale are covered when the stated test fails. No claim is made that every tiling contains such a forbidden configuration.

## Completed N71 test

The target diameter is 142 and c=25. Only endpoints 25*j, 1≤j≤5, which are still in the closed target can matter. The opposite tail is checked against the exact semigroup generated by 10,21,25.

Pruning the already complete 7,618-state tree gives 7,614 states: 285 shifted-strip leaves, 366 exterior-gap leaves and 1,795 empty-candidate leaves. A separate rational checker accepted all states, recomputing the supporting line, positive overlap, opposite half-planes, offsets, admissible endpoints and semigroup condition.

This saves only four states, approximately 0.053%. It is not a substantial acceleration, a new tile-count theorem or evidence of imminent full closure. No nonintegral-offset witness is claimed to have occurred in this tree; that corollary is conditional and analytic.
